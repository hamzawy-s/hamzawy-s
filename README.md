### EduSecure

**Layered Cryptographic Security for an Educational Web Platform** · [Repository](https://github.com/hamzawy-s/edusecure-cryptographic-platform)

An academic security engineering project that demonstrates layered controls for identities, grades, course materials, payment events, and digital credentials. It is a demonstration, not a production deployment.

- **Encryption and key agreement:** TLS 1.2+, X25519 ECDHE, HKDF-SHA256, AES-256-GCM; RSA-3072-OAEP wraps stored-data keys.
- **Authentication and request protection:** PBKDF2 password hashing, signed sessions, role checks, and CSRF tokens.
- **Integrity and event authentication:** HMAC-signed payment webhooks and SHA-256 integrity checks.
- **Digital signatures and trust:** ECDSA P-256 signatures with local X.509 certificate-chain validation.

### FortiGate Multi-Site Security Infrastructure

**PNETLab enterprise-style network security lab** · [Repository](https://github.com/hamzawy-s/three-site-enterprise-network-secured-with-FortiGate-firewalls)

A documented HQ-and-two-branch design with a FortiGate active-passive HA pair, heartbeat and session synchronization, and hub-and-spoke IKEv2 IPsec VPNs. The design covers VLANs for users, servers, management, and DMZ; SSL-VPN; virtual IP/DNAT; firewall policies; and IPS, antivirus, web-filtering, and application-control profiles.

The repository’s verification checklist is still unchecked, so the README presents the architecture and configuration as a lab design rather than claiming every scenario has passed. Its notes also document FortiOS-version limitations and weak cryptographic settings in the lab.
